# Usuários e acessos

Quem entra no sistema, com qual papel e a quais módulos alcança. A tela fica em
**Apoio → Usuários** e tem dois caminhos para criar um acesso — o normal é o
primeiro.

## A tela

<Image src="/assets/guia-usuarios-1.png" alt="Tela de usuários com as áreas numeradas" />

1. **Funcionários sem acesso** — a lista vem do cadastro do RH. É daqui que se
   cria acesso: cada linha tem o botão **Criar acesso**.
2. **O papel de cada acesso** — administrador, gestor, financeiro ou
   operacional, no selo colorido.
3. **Editar e Desativar** — desativar tira a entrada sem apagar o histórico;
   dá para reativar depois.
4. **Novo usuário** — só para quem **não** é funcionário (um contador de fora,
   por exemplo). Funcionário entra pelo caminho 1.

## Dar acesso a um funcionário

Clique em **Criar acesso** na linha do funcionário. O diálogo já vem
preenchido com o que o RH cadastrou:

<Image src="/assets/guia-usuarios-2.png" alt="Diálogo Criar acesso com os campos numerados" />

1. **E-mail** — vira o login. Vem do cadastro; confira antes de criar.
2. **Papel** — o que a pessoa alcança (tabela abaixo). Para quem vai para o
   campo, deixe **Operacional**.
3. **Senha** — o sistema gera uma pronta, sem letras que se confundem na tela
   do celular (0/O, 1/l). O botão ao lado gera outra.
4. **Enviar pelo WhatsApp** — com o número conectado, login e senha chegam
   direto no WhatsApp do funcionário. Sem isso, a senha aparece **uma única
   vez** na tela para você copiar e entregar.
5. **Criar acesso** — pronto: o funcionário já entra.

## Os papéis

| Papel | O que alcança |
|---|---|
| **Administrador** | Acesso total e gestão de usuários |
| **Gestor** | Contratos, locações, aprovação de pagamento e relatórios |
| **Financeiro** | Notas fiscais, contas a pagar e a receber |
| **Operacional** | Campo: saída, retorno, manutenção e almoxarifado — ao logar, cai direto no aplicativo de campo |

Quais módulos cada acesso enxerga é definido pelo suporte; o administrador
gerencia pessoas, papéis e situação.

## Usuário que não é funcionário

<Image src="/assets/guia-usuarios-3.png" alt="Diálogo Novo usuário com os campos numerados" />

1. **E-mail** — o login.
2. **Nome** — como aparece no sistema.
3. **Papel** — os mesmos da tabela.
4. **Senha** — mínimo de 8 caracteres.
5. **Salvar** — a chave **Pode entrar no sistema** deixa o acesso pronto porém
   desligado, útil para preparar antes da pessoa começar.
