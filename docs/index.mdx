# Movimentar ERP

Monorepo `pnpm` + `turbo` com o backend NestJS/Prisma e o front React da
Movimentar Locações.

## Módulos

- **Comercial / Faturamento** — proposta, medição e autorização
- **Contas a pagar**
- **Programação da operação e manutenção** — equipe, líder e execução no PWA de campo
- **Folha de pagamento e RH**

## Especificações

Este repositório é **público** e existe só para o site do docs.page. Os
documentos de requisito e o material de cliente ficam no repositório privado
`devjotaduo/movimentar-erp` e **não** devem ser copiados para cá sem revisão.

## Comandos

```bash
pnpm dev:apps
pnpm test
pnpm lint
```
