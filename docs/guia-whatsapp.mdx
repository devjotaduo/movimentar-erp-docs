# WhatsApp

O sistema envia avisos — medições, alertas, vencimentos, login e senha de novo
usuário — por um número de WhatsApp da empresa. A conexão se faz uma vez, em
**WhatsApp** no menu lateral.

<Image src="/assets/03-whatsapp.png" alt="Tela de conexão do WhatsApp com o código" />

A própria tela guia os três passos, no celular que vai ficar pareado: abra o
WhatsApp, vá em **Dispositivos conectados → Conectar dispositivo** e aponte a
câmera para o código. A tela confere a conexão sozinha a cada 5 segundos — no
momento em que o aparelho lê, ela muda.

Duas coisas para saber:

- O código **vale por poucos minutos**. Se expirar, **Gerar novo código**.
- Ao conectar, o sistema garante o **grupo de notificações** e passa a mandar
  os avisos do sistema para lá. O grupo é criado no momento em que a conexão
  fica pronta.
